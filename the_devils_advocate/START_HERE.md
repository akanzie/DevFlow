## 🚀 Chạy Game Ngay Bây Giờ

### Bước 1: Mở Terminal/Command Prompt
- **Windows**: Nhấn `Win + R` → gõ `cmd`
- **Mac/Linux**: Bấm `Ctrl + Alt + T`

### Bước 2: Di chuyển vào thư mục game
```
cd the_devils_advocate
```

### Bước 3: Chạy game
```
python main.py
```

Nếu lỗi, thử:
```
python3 main.py
```

## ✉️ Menu Chính

Game sẽ hỏi bạn 3 lựa chọn:
- **play** (hoặc Enter) - Bắt đầu chơi
- **help** - Xem hướng dẫn
- **quit** - Thoát

## 🎯 Cách Chơi Cơ Bản

1. Bạn sẽ nhận một **thesis vô lý** để bào chữa
2. AI sẽ **tấn công** bằng các lập luận có ngụy biện
3. Bạn **phản bác** bằng lệnh:
   - `react <lập luận>` - Phản bác tự do
   - `fallacy ad_hominem` - Chỉ ra ngụy biện
   - `evidence <bằng chứng>` - Đưa chứng cứ
   - `hint` - Xin gợi ý

4. **Thắng round** nếu điểm ≥ 80
5. **Thắng game** nếu đạt 1000 điểm

## ⚠️ Lỗi Thường Gặp & Cách Sửa

| Lỗi | Giải Pháp |
|-----|---------|
| "No module named 'game'" | Chạy từ folder `the_devils_advocate` |
| "ModuleNotFoundError" | Cài Python 3.8+ |
| Không thấy màu sắc (Windows) | Dùng Windows Terminal thay Command Prompt |
| Game crash lúc input | Không gõ dấu ngoặc kép, hãy gõ bình thường |

## 📝 Gợi ý Chơi

✅ **Nên làm:**
- Dùng từ khóa logic: "vì", "do đó", "bằng chứng"
- Phát hiện ngụy biện: chỉ ra tên loại khi thấy
- Lập luận dài 2-3 câu, có ví dụ
- Sử dụng từ vựng đa dạng

❌ **Không nên làm:**
- Phản bác quá ngắn (1 từ)
- Chỉ ra sai tên ngụy biện
- Input rỗng hoặc chữ lạo xạo
